SDC Project Defense & Review Guide

Architecture overview & Viva questions cheatsheet

1. Problem Statement & Business System

VaultExpense solves personal and small business financial opacity by providing real-time multi-account tracking, category-wise proactive overspending alerts, automated recurring bill management, and visual analytics using pure client-side web technologies.

2. Architecture & Modules (Admin vs User)
  • Admin Module: User management (create, suspend, promote, reset passwords), Global category taxonomy, System analytics, Security audit trails, and Platform JSON backup.
  • User Module: Dashboard KPIs, Transaction ledger with search/filters, Budget overspend alerts, Multi-account portfolio, Recurring bill reminders, Savings goals with streaks, and CSV/JSON/PDF exports.
3. Technology Stack & Compliance

Built strictly with HTML5, CSS3 (CSS Grid & Flexbox), and Vanilla ES6+ JavaScript. Uses LocalStorage for user authentication and multi-user data scoping (vault_users_db_v1, vault_expense_user_data_*).
